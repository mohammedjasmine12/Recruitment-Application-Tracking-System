\# Recruitment Application Tracking System (ATS)



A full-stack web-based ATS platform to manage job postings, resume screening, candidate tracking, and career portal - built with FastAPI \& JavaScript.



\### 🚀 Live Features

\- \*\*Career Portal:\*\* Public job listing page with dynamic search

\- \*\*Candidate Management:\*\* Apply with Resume Text + Skills parsing

\- \*\*Admin Dashboard:\*\* Create, Edit, Delete Jobs, View Applicants

\- \*\*RESTful API:\*\* FastAPI backend with SQLite \& SQLAlchemy

\- \*\*Clean Architecture:\*\* Backend / Frontend separated



\### 🛠️ Tech Stack

\- \*\*Backend:\*\* Python, FastAPI, SQLAlchemy, SQLite

\- \*\*Frontend:\*\* HTML5, CSS3, Vanilla JavaScript (Fetch API)

\- \*\*Tools:\*\* Git, GitHub, VS Code
